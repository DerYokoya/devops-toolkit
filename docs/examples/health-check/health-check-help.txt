usage: health_check.py [-h] [-f FILE] [-t TIMEOUT] [urls ...]

Check http(s) URLs in parallel and report which ones are unresponsive. Exits with status 1 if any URL is down.

positional arguments:
  urls                  http(s) URLs to check

options:
  -h, --help            show this help message and exit
  -f FILE, --file FILE  text file with one URL per line
  -t TIMEOUT, --timeout TIMEOUT
                        seconds to wait per URL (default: 5)

examples:
  python3 python/monitoring/health_check.py https://example.com https://github.com
  python3 python/monitoring/health_check.py --file urls.txt --timeout 2
  python3 python/monitoring/health_check.py -h
